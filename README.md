 EX No.4.2. CUT SECTION OF SOLIDS

 AIM: 
To create the solid model from given drawing and section the solid model

 REQUIREMENTS: 
1. Autodesk fusion 360
2. Windows 10
3. 16 GB of RAM (integrated graphics recommend 1 GB or more)
4. 2.5 Mbps or faster download; 500 Kbps or faster upload 

 PROCEDURE:
1. Open Autodesk Fusion 360, create a new design and select the XY Plane. Start a 2D sketch and draw a vertical construction line at the centre to represent the axis of the wine glass.

2. Using the Line Tool, draw the half-sectional profile of the glass bowl. Set the outer curved portion with a Radius of R12 mm and form a smooth semicircular bowl shape.

3. Use the Offset Tool to create the inner curved surface of the bowl, maintaining a uniform wall thickness. Close the bowl profile using the required connecting lines.

4. Draw the narrow stem below the bowl using the Line Tool. Maintain the stem's tapered alignment with an angle of approximately 6.79°, as shown in the drawing.

5. Draw the circular base profile at the bottom of the stem. Set the base diameter to Ø2.73 mm and align its centre with the vertical construction axis.

6. Select the Dimension Tool (D) and apply the given measurements: overall vertical dimension 2.56, bowl radius R12, and circular diameters Ø2.71 and Ø2.41. Ensure all dimensions match the engineering drawing.

7. Use the Trim Tool (T) to remove unwanted sketch lines, overlapping curves and extra portions. Check that the bowl, stem and base profiles are properly connected and symmetrical.

8. Finish the sketch and select the Create → Revolve command. Select the closed half-sectional profile and choose the vertical centre construction line as the axis. Set the revolution angle to 360° to create the 3D wine glass.

9. Use the Fillet Tool to smooth the required edges around the bowl, stem and base. Apply suitable finishing details while maintaining the given dimensions and shape.

10. Complete the model by checking the bowl, tapered stem and circular base in Isometric View. Apply the required appearance and material, save the design and verify that the final model matches the given engineering drawing.
